# ERP POS Codex Configuration

This directory contains the project-specific guidance used while developing the
ERP POS MVP. The previous `.agents/` folder was permanently removed, so these
files are now the active project guidance source.

## Documents

- `AGENTS.md`: working agreement for coding agents.
- `project-rules.md`: stack, safety, and implementation rules.
- `SKILL.md`: project workflow for incremental delivery.
- `project-plans.md`: normalized phase checklist and current status.
